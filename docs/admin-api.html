حفلتي · مرجع الـ API للوحة الأدمن (React) · Laravel 12 · Updated 2026-08

Base & Auth

Base URL
https://events-api-production-138b.up.railway.app/api
Auth header
Authorization: Bearer {token}
Content-Type
application/json
Accept
application/json (always send this header)
Roles
both = super_admin + support  ·  super = super_admin only
كل الـ endpoints تبدأ بـ /admin وتحتاج Authorization: Bearer {token} ما عدا /admin/login. الـ token بتاخده من الـ login. في دورين: super_admin عندو كل شي، وsupport عندو العرض + الموافقة على الفيندور (KYC) + الدعم فقط — بلا فلوس أو حظر أو حذف محتوى. المسارات المعلّمة super بترجع 403 لو ناداها support. كل الردود مغلّفة بـ { "status": "success" | "error", ... }، والقوائم مصفّحة (Laravel pagination: data, current_page, last_page, total).

1 · Authentication — تسجيل الدخول

POST/admin/login🌐 Public · throttled 5/min
Job
تسجيل دخول الأدمن. بيرجّع token + بيانات الأدمن. 401 لو الإيميل/كلمة السر غلط. محدود بـ 5 محاولات بالدقيقة.
Body
FieldTypeRequiredالشرح
emailstringrequiredإيميل الأدمن (غير حسّاس لحالة الأحرف).
passwordstringrequiredكلمة السر.
Response
{ "status":"success", "token":"…", "admin":{ "id":1, "name":"…", "email":"…", "role":"super_admin" } }
POST/admin/logout🔒 any admin
Job
يلغي الـ token الحالي.
Body
No body.

2 · Dashboard & Stats — اللوحة والإحصائيات

GET/admin/dashboard🔒 both
Job
أرقام اللوحة الرئيسية + عدّادات الشريط الجانبي (النقاط الحمرا).
Response
{ "status":"success", "stats":{ "total_users","total_vendors","approved_vendors","pending_vendors", "banned_vendors","total_bookings","active_bookings","completed_bookings", "profit_today","profit_month","profit_all_time" }, "nav_badges":{ "pending_vendors","unread_support","reported_content", "refunds_due","unpaid_withdrawals" } }
GET/admin/stats/financial🔑 super
Job
التقرير المالي الكامل. summary إجمالي، وnet صافي الربح الحقيقي، ونوافذ زمنية، ومنحنى 12 شهر جاهز للرسم.
Response
{ "status":"success", "currency":"SYP", "summary":{ "gross_volume","platform_profit","vendor_payouts","transactions" }, "net":{ "gross_profit","refunded_to_customers","commission_lost", "commission_reclaimed","net_profit" }, "today":{…}, "this_month":{…}, "this_year":{…}, "monthly_trend":[ { "month":"2026-08","gross_volume","platform_profit","transactions" }, … ] }

3 · Notifications — the bell — جرس الإشعارات

سجل أحداث لكل أدمن (حالة "مقروء" مستقلة). كل إشعار فيه data.type = vendor_kyc · support · content_report · withdrawal · refund_due + رقم الهدف للتنقّل.

GET/admin/notifications🔒 any admin
Job
إشعارات هذا الأدمن (الأحدث أولاً) + unread_count.
Response
{ "status":"success", "unread_count":3, "notifications":[ { "id","title","body","read_at","created_at","data":{ "type","…id" } }, … ] }
POST/admin/notifications/read-all🔒 any admin
Job
تعليم كل إشعارات هذا الأدمن كمقروءة.
Body
No body.
POST/admin/notifications/{id}/read🔒 any admin
Job
تعليم إشعار واحد مقروء. 404 لو مش إشعار هذا الأدمن.
Body
No body.

4 · Vendors — الفيندورية

GET/admin/vendors🔒 both
Job
قائمة مصفّحة. كل فيندور فيه account_status محسوب.
Query
ParamTypeالشرح
searchstringاسم / اسم نشاط / هاتف.
statusenumkyc_pending · active · winding_down · banned — تبويبات الحالة الأربعة (تقسيم تام).
is_active0 | 1فلتر بديل بسيط (لسا يشتغل).
GET/admin/vendors/pending🔒 both
Job
طابور KYC — الفيندورية المنتظرين موافقة (غير محظورين). مصفّح.
Body
No body.
GET/admin/vendors/{id}🔒 both
Job
فيندور واحد + منتجاته + bookings_count + reviews_count + account_status.
Body
No body.
POST/admin/vendors/{id}/approve🔒 both
Job
موافقة KYC → is_approved=true.
Body
No body.
POST/admin/vendors/{id}/reject🔒 both
Job
رفض KYC (لا يحظر فيندور فعّال — الحظر منفصل).
Body
FieldTypeRequiredالشرح
reasonstringrequiredسبب الرفض، حتى 1000. بينحفظ على الفيندور.
POST/admin/vendors/{id}/ban🔑 super
Job
حظر فوري (احتيال). يلغي + يرجّع كل الحجوزات الجارية، ويسحب عمولة المنصة من الفيندور على الحجوزات المعتمدة. الرد فيه cancelled_bookings + commission_charged.
Body
FieldTypeRequiredالشرح
reasonstringoptionalسبب الحظر، حتى 1000.
POST/admin/vendors/{id}/ban-gradual🔑 super
Job
حظر تدريجي. يرجّع المعلّقة، يخلّي المعتمدة تكمل، يحظر تلقائياً لما تخلص. بلا سحب عمولة. → winding_down.
Body
FieldTypeRequiredالشرح
reasonstringoptionalسبب الحظر.
POST/admin/vendors/{id}/unban🔑 super
Job
إعادة تفعيل فيندور محظور/متوقّف → active.
Body
No body.
GET/admin/vendors/{id}/wallet🔑 super
Job
محفظة الفيندور + السجل الكامل. available_balance ممكن يكون سالب (مدين للمنصة بعد سحب عمولة).
Response
{ "status":"success", "vendor":{ "id","business_name" }, "wallet":{ "available_balance","pending_clearance","total_earned","currency" }, "transactions":[ … ] }

6 · Bookings & Disputes — الحجوزات والنزاعات

GET/admin/bookings🔒 both
Job
قائمة مصفّحة (مع المستخدم والفيندور والمنتج).
Query
ParamTypeالشرح
statusstringawaiting_payment · pending · approved · declined · completed · cancelled
vendor_idintegerحجوزات فيندور معيّن.
user_idintegerحجوزات مستخدم معيّن.

POST/admin/bookings/{id}/cancel🔑 super
Job
حل نزاع. يلغي حجز واحد، يرجّع للزبون 100%، يعكس رصيد الفيندور — بلا سحب عمولة (الخطأ غير واضح).
Body
FieldTypeRequiredالشرح
reasonstringrequiredسبب الإلغاء.
POST/admin/bookings/{id}/cancel-vendor-request🔑 super
Job
إلغاء بطلب الفيندور. فقط لحجز approved (422 غير هيك). يرجّع للزبون 100% ويسحب العمولة من الفيندور (هو السبب). الرد: refund_amount + commission_charged.
Body
FieldTypeRequiredالشرح
reasonstringoptionalسبب الإلغاء.

7 · Support — الدعم

صندوق وارد واحد للتيكيتات (المستخدمين) والمحادثات (الفيندورية). الأحداث بتنخلق من التطبيق (شوف آخر الصفحة). كلا الدورين يتعامل مع الدعم.

GET/admin/support🔒 both
Job
صندوق الوارد. كل خيط فيه owner_name، owner_phone، unread_count. + كائن counts.
Query
ParamTypeالشرح
owner_typeenumuser · vendor
statusenumopen · in_review · resolved
unread1الخيوط اللي فيها رسالة غير مقروءة فقط.
GET/admin/support/{id}🔒 both
Job
الخيط الكامل: كل الرسائل + owner + سياق الحجز (فيندور/منتج/دفعة) لتيكيتات المستخدمين. الفتح يعلّم رسائل الطرف الآخر مقروءة.
Body
No body.
POST/admin/support/{id}/messages🔒 both
Job
رد الأدمن. على تيكيت جديد → يفتح المحادثة (in_review)، يضبط handled_by، ويشعر الطرف الآخر.
Body
FieldTypeRequiredالشرح
messagestringrequiredنص الرد، حتى 5000.
POST/admin/support/{id}/resolve🔒 both
Job
إغلاق الخيط (مسجّل بالتدقيق، الطرف الآخر بينشعر). تيكيت المستخدم بيضل مغلق؛ محادثة الفيندور بتنفتح لو كتب مجدداً.
Body
No body.

MethodEndpointGuardالشرح
