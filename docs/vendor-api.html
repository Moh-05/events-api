Base & Auth

Base URL
https://events-api-production-138b.up.railway.app/api
Auth header
Authorization: Bearer {token}
Content-Type
application/json — except image uploads → multipart/form-data
Accept
application/json (always send this header)
كل الـ endpoints تحتاج الـ Authorization: Bearer {token} ما عدا تسجيل الدخول (send-otp / verify-otp / complete-registration). الـ token بتاخذه من الـ login. للتجربة الحالية: الـ otp برجع جوّا الـ response مباشرة، فما بتحتاج WhatsApp. أي طلب فيه رفع صور (المنتجات أو صورة البروفايل) لازم يكون multipart/form-data، والباقي JSON.

1 · Authentication — تسجيل الدخول والتسجيل

POST/vendor/send-otp🌐 Public
Job
يرسل رمز تحقق (OTP) لرقم الموبايل عبر WhatsApp. للتجربة الرمز برجع جوّا الـ response بحقل otp.
Body
FieldTypeRequiredالشرح
phonestringrequiredرقم الموبايل، أرقام فقط مع إمكانية + (7–15 خانة).
POST/vendor/verify-otp🌐 Public
Job
يتحقق من الـ OTP. إذا الرقم موجود مسبقاً → بيرجّع status: login مع token. إذا جديد → بيرجّع status: new_vendor مع registration_token لإكمال التسجيل.
Body
FieldTypeRequiredالشرح
phonestringrequiredنفس الرقم المُرسل له الـ OTP.
otpintegerrequiredالرمز المكوّن من 6 أرقام.
POST/vendor/complete-registration🌐 Public
Job
ينشئ حساب الـ vendor الجديد ويرجّع الـ token. يُستدعى فقط لما يكون الرقم جديد (بعد new_vendor).
Body
FieldTypeRequiredالشرح
registration_tokenstringrequiredالـ token الراجع من verify-otp (صالح 15 دقيقة).
first_namestringrequiredحروف فقط، 2–50.
last_namestringrequiredحروف فقط، 2–50.
citystringrequiredالمدينة، 2–100.
birth_datedaterequiredتاريخ ميلاد صالح (YYYY-MM-DD) قبل اليوم.

2 · Profile — الملف الشخصي

GET/vendor/profile🔒 Token
Job
يرجّع بيانات الـ vendor الحالي (المسجّل دخوله بالـ token).
Body
No body.
POST/vendor/profile/type🔒 Token
Job
يحدّد نوع الـ vendor (يُضبط مرة بعد التسجيل). النوع بيحدّد الـ booking_style تلقائياً (cake_shop = order، الباقي = appointment).
Body
FieldTypeRequiredالشرح
vendor_typestringrequiredواحد من: wedding_venue · photographer · cake_shop · dj
POST/vendor/profile🔒 Token
Job
يحدّث بيانات البروفايل. كل الحقول اختيارية — أرسل فقط ما تريد تغييره. لرفع صورة بروفايل استخدم multipart/form-data.
Body (multipart/form-data if sending an image)
FieldTypeRequiredالشرح
business_namestringoptionalاسم النشاط، حتى 255.
biostringoptionalنبذة، حتى 1000.
birth_datedateoptionalتاريخ الميلاد.
latitudenumericoptionalخط العرض (−90 … 90).
longitudenumericoptionalخط الطول (−180 … 180).
addressstringoptionalالعنوان، حتى 255.
profile_imagefileoptionalصورة jpg/jpeg/png، حد أقصى 2MB.
DELETE/vendor/profile/image🔒 Token
Job
يحذف صورة البروفايل الحالية.
Body
No body.
POST/vendor/fcm-token🔒 Token
Job
يخزّن الـ FCM token تبع جهاز الـ vendor لإرسال إشعارات Push. يرسله التطبيق بعد تسجيل الدخول.
Body
FieldTypeRequiredالشرح
fcm_tokenstringrequiredالـ device token من Firebase.

3 · Products / Services — المنتجات / الخدمات

GET/vendor/products🔒 Token
Job
يرجّع كل منتجات/خدمات الـ vendor المتاحة، مع صورها.
Body
No body.
POST/vendor/products🔒 Token
Job
ينشئ منتج/خدمة جديدة. الصور مطلوبة. الطلب لازم يكون multipart/form-data. ملاحظة: نسبة العربون (deposit) ثابتة 20% ولا تُرسل.
Body (multipart/form-data)
FieldTypeRequiredالشرح
images[]file[]requiredصورة واحدة على الأقل، jpg/jpeg/png، حد أقصى 2MB لكل صورة.
namestringoptionalاسم المنتج، حتى 255.
descriptionstringoptionalالوصف.
pricenumericoptionalالسعر (≥ 0).
stockintegeroptionalالكمية (لمتاجر الطلبات مثل cake_shop).
metaarrayoptionalبيانات إضافية حرّة (key/value).
primary_image_indexintegeroptionalترتيب الصورة الرئيسية (افتراضي 0).
GET/vendor/products/best-sellers🔒 Token
Job
أكثر 5 منتجات مبيعاً (حسب عدد الحجوزات المدفوعة/النشطة).
Body
No body.
GET/vendor/products/low-stock🔒 Token
Job
المنتجات التي وصلت أو نزلت عن حدّ المخزون (تنبيهات النفاد).
Query params
FieldTypeRequiredالشرح
thresholdintegeroptionalالحد الأدنى (افتراضي 5). مثال: ?threshold=3
GET/vendor/products/{id}🔒 Token
Job
يرجّع منتج واحد بالتفصيل (للـ vendor صاحب المنتج فقط).
Path
FieldTypeRequiredالشرح
{id}integerrequiredرقم المنتج في الـ URL.
POST/vendor/products/{id}🔒 Token
Job
يحدّث المنتج: تعديل الحقول، إضافة صور جديدة، أو حذف صور موجودة. كل الحقول اختيارية. استخدم multipart/form-data عند إرسال صور.
Path & Body (multipart/form-data if images)
FieldTypeRequiredالشرح
{id}integerrequiredرقم المنتج في الـ URL.
name / description / price / stock / metamixedoptionalنفس حقول الإنشاء — أرسل فقط ما تريد تعديله.
images[]file[]optionalصور جديدة تُضاف للمنتج.
delete_image_ids[]integer[]optionalأرقام الصور المراد حذفها.
primary_image_indexintegeroptionalتحديد الصورة الرئيسية.
DELETE/vendor/products/{id}🔒 Token
Job
يحذف المنتج وكل صوره.
Path
FieldTypeRequiredالشرح
{id}integerrequiredرقم المنتج في الـ URL.

4 · Bookings & Orders — الحجوزات والطلبات

حالات الحجز (status): awaiting_payment بانتظار الدفع (مخفي عن الـ vendor) · pending مدفوع وبانتظار موافقتك · approved تمت الموافقة · completed منتهٍ · declined مرفوض · cancelled ملغى
GET/vendor/bookings🔒 Token
Job
كل حجوزات الـ vendor (الأحدث أولاً) مع المنتج المرتبط.
Body
No body.
GET/vendor/bookings/recent-requests🔒 Token
Job
آخر 10 طلبات حجز بحالة pending (بانتظار موافقتك)، مع اسم العميل والمنتج.
Body
No body.
GET/vendor/bookings/recent-orders🔒 Token
Job
آخر 10 طلبات لمتاجر الطلبات (booking_style = order)، بدون المسوّدات غير المدفوعة.

No body.

7 · Wallet — المحفظة

منطق المحفظة: عند موافقة الـ vendor على حجز، يُضاف مبلغه للمحفظة لكنه محجوز 3 أيام (فترة استرجاع العميل). بعد 3 أيام يصبح متاحاً للسحب. available_balance القابل للسحب الآن · pending_clearance محجوز ضمن الـ 3 أيام · total_earned الأرباح المؤكدة (بعد خصم الاسترجاعات).
GET/vendor/wallet🔒 Token
Job
يرجّع أرصدة المحفظة (available / pending / total earned) + سجل الحركات (transactions). كل حركة تحتوي الـ booking مع العميل والمنتج. المبلغ amount بإشارة (سالب = خروج).
Body
No body.
POST/vendor/withdraw🔒 Token
Job
يسحب كامل الرصيد المتاح (available_balance) ويصفّره. (الدفع الفعلي للبنك سيُضاف لاحقاً عند توفّر ShamCash payout API.) يرجّع خطأ 422 إذا لا يوجد رصيد متاح.
Body
No body.
