Haflati — Vendor App API Reference

حفلتي · مرجع الـ API لتطبيق الـ Vendor (Flutter) · Laravel 12 · Updated 2026-06-15

Base & Auth

Base URL
https://events-api-production-138b.up.railway.app/api
Auth header
Authorization: Bearer {token}
Content-Type
application/json — except image uploads → multipart/form-data
Accept
application/json (always send this header)
كل الـ endpoints تحتاج الـ Authorization: Bearer {token} ما عدا تسجيل الدخول (send-otp / verify-otp / complete-registration). الـ token بتاخذه من الـ login. للتجربة الحالية: الـ otp برجع جوّا الـ response مباشرة، فما بتحتاج WhatsApp. أي طلب فيه رفع صور (المنتجات أو صورة البروفايل) لازم يكون multipart/form-data، والباقي JSON.

Common Responses — ردود مشتركة

هي الردود ممكن ترجع من أي endpoint، فمذكورة هون مرّة وحدة بدل ما تتكرر بكل نقطة. تحت كل endpoint بنذكر بس الردود الخاصة فيه. كل الردود JSON. النجاح غالباً فيه "status": "success"، والخطأ فيه "status": "error" و "message".
401Unauthenticated — التوكن ناقص أو غير صالح (على أي endpoint محمي). أرسل دائماً Accept: application/json وإلا بيرجع redirect.
"message": "Unauthenticated."
403Account suspended — الحساب محظور من الأدمن (يمنع تسجيل الدخول واستخدام الـ endpoints).
{
  "status": "suspended",
  "message": "Your account has been suspended. Please contact support."
}
422Validation error — حقل ناقص أو غير صحيح. errors فيه رسالة لكل حقل. (مثال عام).
{
  "message": "The phone field is required.",
  "errors": {
    "phone": ["The phone field is required."]
  }
}

1 · Authentication — تسجيل الدخول والتسجيل

POST/vendor/send-otp🌐 Public
Job
يرسل رمز تحقق (OTP) لرقم الموبايل عبر WhatsApp. للتجربة الرمز برجع جوّا الـ response بحقل otp.
Body
FieldTypeRequiredالشرح
phonestringrequiredرقم الموبايل، أرقام فقط مع إمكانية + (7–15 خانة).
Responses
200تم الإرسال. otp يظهر للتجربة فقط. ultramsg_status=404 يعني اشتراك WhatsApp موقوف حالياً (طبيعي بالتجربة).
{
  "message": "OTP sent",
  "otp": 834192,
  "ultramsg_status": 404,
  "ultramsg_response": { /* رد WhatsApp */ }
}
422رقم غير صالح (فاضي، أحرف، أو خارج 7–15 خانة).
{ "message": "The phone field is required.", "errors": { "phone": [ "..." ] } }
POST/vendor/verify-otp🌐 Public
Job
يتحقق من الـ OTP. إذا الرقم موجود مسبقاً → بيرجّع status: login مع token. إذا جديد → بيرجّع status: new_vendor مع registration_token لإكمال التسجيل. إذا الحساب محظور → status: suspended (403).
Body
FieldTypeRequiredالشرح
phonestringrequiredنفس الرقم المُرسل له الـ OTP.
otpintegerrequiredالرمز المكوّن من 6 أرقام.
Responses
200الرقم موجود مسبقاً — تسجيل دخول. يرجّع token وكامل بيانات الـ vendor.
{
  "status": "login",
  "token": "12|aBcD3fGhIjKlMnOpQrStUvWxYz...",
  "vendor": {
    "id": 7,
    "first_name": "Sara",
    "last_name": "Ahmad",
    "phone": "+963991234567",
    "vendor_type": "photographer",
    "booking_style": "appointment",
    "is_accepting_bookings": true,
    "profile_image_url": null,
    "cover_image_url": null,
    "account_status": "active"
    /* ... باقي حقول الـ vendor. fcm_token غير موجود أبداً */
  }
}
200رقم جديد — يرجّع registration_token (صالح 15 دقيقة) لإكمال التسجيل.
{
  "status": "new_vendor",
  "registration_token": "a1b2c3...64chars"
}
400الـ OTP خاطئ أو منتهي الصلاحية.
{ "message": "Invalid OTP" }
403الحساب محظور نهائياً من الأدمن — يمنع الدخول.
{
  "status": "suspended",
  "message": "Your account has been suspended. Please contact support."
}
POST/vendor/complete-registration🌐 Public
Job
ينشئ حساب الـ vendor الجديد ويرجّع الـ token. يُستدعى فقط لما يكون الرقم جديد (بعد new_vendor). الـ vendor_type بيحدّد الـ booking_style تلقائياً (فئات البيع = order، فئات الخدمات = appointment).
Body
FieldTypeRequiredالشرح
registration_tokenstringrequiredالـ token الراجع من verify-otp (صالح 15 دقيقة).
first_namestringrequiredحروف فقط، 2–50.
last_namestringrequiredحروف فقط، 2–50.
citystringrequiredالمدينة، 2–100.
birth_datedaterequiredتاريخ ميلاد صالح (YYYY-MM-DD) قبل اليوم.
vendor_typestringrequiredالفئة. خدمات: photographer · makeupArtist · dj · weddingHall · بيع: flowers · gifts · dresses · accessories · candles · cakes
vendor_stylestringoptionalservice_provider · seller — حقل مساعد للتطبيق فقط (بدون منطق بالـ backend)، بيرجع مع بيانات الـ vendor.
Responses
200تم إنشاء الحساب. يرجّع token وبيانات الـ vendor الجديد. booking_style اتحدّد تلقائياً حسب الفئة.
{
  "status": "success",
  "token": "13|xYzAbCdEfGhIjKlMnOpQr...",
  "vendor": {
    "id": 42,
    "first_name": "Sara",
    "last_name": "Ahmad",
    "phone": "+963991234567",
    "city": "Damascus",
    "birth_date": "1998-04-12T00:00:00.000000Z",
    "vendor_type": "cakes",
    "booking_style": "order",
    "vendor_style": "seller",
    "is_approved": false,
    "is_active": true,
    "is_accepting_bookings": true,
    "profile_image_url": null,
    "cover_image_url": null,
    "account_status": "active"
    /* ... created_at / updated_at. fcm_token غير موجود أبداً */
  }
}
403الـ registration_token منتهي الصلاحية أو غير صالح.
{ "message": "Expired" }
422حقل ناقص أو غير صالح (مثلاً vendor_type خارج القائمة، أو first_name فيه أرقام).
{ "message": "The selected vendor type is invalid.", "errors": { "vendor_type": [ "..." ] } }
